# 出欠連絡フォームの作り方

会（女性部・青年部・議員など）ごとに出欠連絡フォームを用意し、その回答通知メールを
アプリの「メールから出欠を取り込む」機能で会議の出欠へ自動反映するための手順です。

**フォーム自体は会ごとに別々に作って構いません。**
ただし、**通知メールの本文だけは全会で同じ書式に揃えてください。**
書式さえ揃っていれば、アプリ側の設定変更なしにどの会でも取り込めます。

## 1. 通知メールの書式（必守）

アプリは本文から **`【ラベル】値`** の形で各項目を読み取ります。

```
【出欠】出席
【事業所名】株式会社○○商事
【氏名】山田 太郎
【代理役職】部長
【代理者名】鈴木 花子
【備考】途中退席します
```

### ルール

| ルール | 内容 |
|---|---|
| ラベルは全角の隅付き括弧 | `【` `】` で囲む。`[出欠]` や `出欠:` は認識しません |
| 値はラベルの直後 | 次の `【` が現れるまでが値です（**複数行の入力も可**） |
| 項目の順序 | 自由。上記の順でなくても構いません |
| 使わない項目 | 省略可。代理制度のない会は `【代理役職】【代理者名】` を省けます |
| 余計な文章 | 最初の `【` より前にあいさつ文などがあっても問題ありません |

> 値の中に `【` を使わないでください。そこで値が切れてしまいます。

### 【出欠】に入れる値（完全一致）

| 入れる値 | アプリでの扱い |
|---|---|
| `出席` | 出席 |
| `出席(※代理)` | 代理 |
| `委任` | 委任 |
| `欠席` | 欠席 |

> **この4つ以外の文字列は認識されません。** 認識できなかった行は取込画面で
> 出欠欄が空欄になり、反映されずにスキップされます（誤ったデータは入りません）。
> 「出席します」「○出席」などにならないよう、フォームの選択肢の文言をそのまま
> この4つにしてください。
>
> `出席(※代理)` の括弧は**半角**、`※` は全角です。コピーして使ってください。

### 【事業所名】について

アプリは**事業所名で名簿の会員を突合**します。氏名では突合しません。

- 突合時は法人格（`株式会社` `有限会社` `合同会社` `㈱` `（株）` `(株)` `㈲` `（有）` `(有)`）と
  空白を自動で除去して比較するため、`株式会社○○商事` と `○○商事` はどちらでも一致します。
- 完全一致が無い場合は、包含関係（例：メール「近鉄百貨店」⊂ 名簿「近鉄百貨店四日市店」）でも一致します。
- それでも一意に決まらない場合は、取込画面で会員を手動選択します。
  一度選ぶと次回から自動で同じ会員に紐付きます（「事業所名の紐付けを管理...」で確認・修正可）。

> 会員が事業所ではなく個人で登録されている会でも、名簿の「事業所名」欄に入れている
> 名称をフォームで入力してもらえば突合できます。

## 2. フォームの雛形

以下をそのままフォームの設問にしてください。

| 設問文 | 種類 | 必須 | 選択肢・備考 |
|---|---|---|---|
| 出欠 | 選択（単一） | ◎ | `出席` / `出席(※代理)` / `委任` / `欠席` |
| 事業所名 | 記述（1行） | ◎ | 名簿に登録されている名称で入力してもらう |
| 氏名 | 記述（1行） | ◎ | |
| 代理役職 | 記述（1行） | | 「出欠」で`出席(※代理)`を選んだときのみ表示（分岐設定） |
| 代理者名 | 記述（1行） | | 同上 |
| 備考 | 記述（複数行） | | |

代理制度のない会は「代理役職」「代理者名」を省き、出欠の選択肢も
`出席` / `委任` / `欠席` の3つにして構いません。

## 3. 作成手順（Microsoft Forms ＋ Power Automate）

Microsoft Forms の標準の回答通知メールは書式が固定で、上記の形式になりません。
**Power Automate（自動化フロー）で、決まった書式のメールを自分あてに送る**構成にします。

### 3-1. フォームを作る

1. [https://forms.office.com](https://forms.office.com) を開く
2. 「新しいフォーム」→ [2. フォームの雛形](#2-フォームの雛形) のとおりに設問を作る
3. 「出欠」の選択肢は、上表の4つを**コピーして貼り付け**る（打ち間違い防止）
4. 「代理役職」「代理者名」は、設問の「…」→「分岐を追加する」で
   出欠が `出席(※代理)` のときだけ表示されるようにする（任意）

### 3-2. 通知メールを送るフローを作る

1. [https://make.powerautomate.com](https://make.powerautomate.com) を開く
2. 「作成」→「自動化したクラウド フロー」
3. トリガーに **「新しい応答が送信されるとき」（Microsoft Forms）** を選び、作成したフォームを指定
4. 「新しいステップ」→ **「応答の詳細を取得する」（Microsoft Forms）** を追加  
   フォームIDに同じフォーム、応答IDに前の手順の「応答ID」を指定
5. 「新しいステップ」→ **「メールの送信 (V2)」（Office 365 Outlook）** を追加

   | 項目 | 設定内容 |
   |---|---|
   | 宛先 | 出欠を集約する担当者または共有メールボックスのアドレス |
   | 件名 | `【出欠連絡】女性部` のように、**会ごとに固有の文字列**を入れる |
   | 本文 | 下記のとおり（動的なコンテンツで各設問の回答を差し込む） |

   本文（`〈 〉` の部分に「動的なコンテンツ」から各設問の回答を挿入）：

   ```
   【出欠】〈出欠〉
   【事業所名】〈事業所名〉
   【氏名】〈氏名〉
   【代理役職】〈代理役職〉
   【代理者名】〈代理者名〉
   【備考】〈備考〉
   ```

6. 本文欄の書式設定は**「コードビュー」または書式なし**にする  
   （リッチテキストで装飾すると、`【` と値の間にHTMLタグが入り読み取れなくなることがあります）
7. 保存し、フォームからテスト送信して受信メールを確認する

> **件名は会ごとに変えてください。** アプリの「対象件名」に指定して、
> 他の会の連絡メールが混ざらないようにします。

### 代替手段

Power Automate が使えない場合は、上記の本文書式でメールを送れるものであれば
何でも構いません（自社Webフォーム、Googleフォーム＋GAS など）。
重要なのは **本文の書式** と **件名に会ごとの固有文字列を入れること** の2点だけです。

## 4. Outlook の仕分けルール

出欠連絡メールを専用フォルダに集めます。

1. Outlook で受信トレイの下に、会ごとのフォルダを作る（例：`女性部出欠`）
2. 「ホーム」→「ルール」→「仕分けルールの作成」
3. 条件：**件名に** 3-2 で決めた文字列（例：`【出欠連絡】女性部`）**が含まれる**
4. 処理：作成したフォルダへ移動する

> フォルダは受信トレイの下の階層にあっても構いません（アプリが再帰的に探します）。
> ただし**フォルダ名は他と重複しないように**してください。

## 5. アプリ側の設定

会議管理タブ →「事前入力」→「**メールから出欠を取り込む**」を開き、次を入力します。

| 項目 | 入力内容 |
|---|---|
| 対象フォルダ名 | 4 で作った Outlook のフォルダ名（例：`女性部出欠`） |
| 対象件名（部分一致・空欄可） | 3-2 で決めた件名の文字列（例：`【出欠連絡】女性部`） |

この2つは**会ごとに記憶される**ため、次回以降は入力不要です。

### Entra ID のアクセス許可

出欠メールの読み取りには、送信用の `Mail.Send` とは別に **`Mail.Read`（委任）** が必要です。
未設定の場合は管理者マニュアルの
[2-6. API アクセス許可の設定](管理者マニュアル.md#2-6-api-アクセス許可の設定) を参照して追加してください。

## 6. 事前確認（テスト）

本番の会議で使う前に、必ず1件テストしてください。

1. テスト用の会議を作る（会議管理タブ →「新規作成」）
2. 自分でフォームに回答する（事業所名は、名簿に登録済みの会員のものを使う）
3. Outlook で対象フォルダにメールが入ることを確認する
4. アプリの「メールから出欠を取り込む」→「検索」
5. 一覧に出た行で、次を確認する
   - **出欠**欄が空でないこと（空なら選択肢の文言が4つのいずれかと一致していない）
   - **会員**欄に正しい会員が自動で入っていること（空なら手動で選ぶ）
6. 「選択した行を反映」で事前入力に入ることを確認する
7. テスト用の会議を削除する

## 7. うまく取り込めないとき

| 症状 | 原因と対処 |
|---|---|
| 一覧に何も出ない | フォルダ名の入力ミス、または件名フィルタが一致していない。件名を空欄にして再検索し、出るなら件名の指定が原因 |
| 「フォルダが見つかりません」 | Outlook のフォルダ名と入力が一致していない。名前をコピーして貼り付ける |
| 事業所名・氏名が空欄になる | 本文の書式が崩れている。`【` `】` が全角か、リッチテキストの装飾が入っていないか確認する。受信メールを「メッセージのソース」で確認すると分かりやすい |
| 出欠欄が空欄で反映されない | 【出欠】の値が `出席` `出席(※代理)` `委任` `欠席` のいずれとも一致していない。フォームの選択肢の文言を修正する |
| 会員欄が空欄 | 事業所名が名簿と一致しない、または複数候補がある。取込画面で会員を選ぶと次回から自動で紐付く |
| 別の会の連絡が混ざる | 件名に会ごとの固有文字列を入れ、Outlook の仕分け先フォルダも会ごとに分ける |
| 同じ人の連絡が複数ある | 同一事業所からの複数回答は**最新の1件だけ**が一覧に残ります（正常な動作です） |
